# 📖 Overview

On Day 7, I learned one of Python's most useful data structures: **Dictionaries**.

# 📚 Key Concepts Learned

- Dictionaries store data as **key-value pairs**.
- Keys must be unique.
- Values can be duplicated.
- Dictionaries are mutable.
- Fast searching using keys.
- Looping through dictionaries using:
  - `for key in dictionary`
  - `dictionary.keys()`
  - `dictionary.values()`
  - `dictionary.items()`
- Counting frequencies using dictionaries.
- Building menu-driven programs using dictionaries.
