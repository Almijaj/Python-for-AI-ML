## 📚 Important Concepts Learned

### Tuple

A tuple is an ordered and immutable collection of elements.

```python
numbers = (10, 20, 30, 40, 50)
```

Tuples cannot be modified after creation.

### Set

A set is an unordered collection of unique elements.

```python
numbers = {10, 20, 30, 40}
```

Sets automatically remove duplicate values.

## 🔑 Important Methods and Operations

### Tuple

```python
tuple.index()
len(tuple)
tuple[::-1]
```

### Set

```python
set.add()
set.difference()
set.symmetric_difference()
set.intersection()
set.union()
```

## 🧠 Quick Revision

```text
List  → Mutable and ordered
Tuple → Immutable and ordered
Set   → Unique elements and unordered
```

### Key Points

* Tuples are immutable.
* Lists are mutable.
* Sets store unique values.
* Sets automatically remove duplicates.
* `add()` adds an element to a set.
* `difference()` finds elements present in one set but not another.
* `symmetric_difference()` finds elements present in either set but not both.
* `[::-1]` can be used to reverse a tuple.
